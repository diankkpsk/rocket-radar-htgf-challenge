Before the demo run python3 run.py and open http://127.0.0.1:8766/. The package contains dated public evidence for an offline demonstration. A live scan needs network access. Choose replay if the venue cannot access public sources, and keep the mode visible.

## 0:00–0:40

Open HTGF portfolio. Show the stored 541-record total. Search robotics, which currently returns 20 public portfolio entries. Open a dossier and its original HTGF link. Explain the field coverage and unknowns.

## 0:40–1:20

Open Discovery. Remove the Germany focus chip to see all 27 prospects including unverified locations. Switch between pre-company, new registrations and emerging. In New registrations use the 30-day window, open a company and show the official registration number/date plus its low venture-quality score.

## 1:20–2:10

Open IsoSphere Technologies using the Best Find card. Inspect the team and its professional source, customer-discovery evidence and the four publisher groups. Explain that the buyer-interest figures are reported by the source. Show the distinct quality/confidence measures and historical source dates beside the November engine observation. Export the memo.

## 2:10–2:45

Run a TUM source scan in live mode. The bounded directory scan normally takes several seconds. The same-day rerun should report existing records unchanged. Open Scan history and inspect the mode, counts and any actual errors. A keyless Companies House attempt demonstrates its visible configuration requirement. On a network failure select replay of the stored public recording and explain the switch.

## 2:45–3:00

Save a candidate to the watchlist, show Sources and country coverage, then open the query planner. Explain that 20 additional campus pages are available for manual research and most country entries await automated adapter implementation.

If a source page has changed, show the failure result and continue using recorded evidence. Keep source facts, capture dates and open diligence questions visible.
